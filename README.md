# 糖尿病控制不良評估互動網頁

網址：https://yht5582-source.github.io/diabetes-controll/

可互動填寫的糖尿病控制不良原因評估、跨職類協作與追蹤評值工具，內容對應 Excel 版「糖尿病控制不良原因評估表_協作追蹤評值版」。

## 內容

- `index.html`：互動網頁入口
- `styles.css`：網頁樣式（含手機版與列印版）
- `app.js`：計分、摘要、本機自動儲存、CSV 匯出、JSON 備份／匯入；計算邏輯在 `/*ENGINE-START*/…/*ENGINE-END*/`
- `tests.cjs`：計算邏輯測試（`node tests.cjs`）
- `糖尿病控制不良原因評估表_協作追蹤評值版.xlsx`：Excel 版本

## 功能

1. 基本資料與目標（含糖尿病類型、目前治療、基準／目標 HbA1c）
2. 常見控制不良原因檢核（10 項，是否存在、改善計畫、完成狀態）
3. 改善措施與追蹤（依勾選原因標示建議措施）
4. 跨職類協作（職類、評估重點、發現、建議、醫師評論）
5. 追蹤紀錄（同一病人多筆；血糖單位 mg/dL，超出合理範圍會提示）
6. 評值系統：5 面向加權 0–5 分，全部評分後才判定等第（≥85 A、70–84 B、60–69 C、<60 D）

摘要列顯示總分、等第、最近 HbA1c（較基準變化與是否達標）、最新改變、下次評估日（依最近追蹤紀錄，逾期會標示）。

資料自動儲存在本機瀏覽器，不會上傳；共用電腦使用後請按「新病人」清除。可用「備份」下載 JSON、「匯入」還原。
